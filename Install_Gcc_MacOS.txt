================================================================================
          GNU GCC & SDR COMPONENT INSTALLATION GUIDE FOR LINUX
================================================================================

This guide walks you through installing a pure GNU GCC compiler environment and 
essential Software Defined Radio (SDR) ecosystems on Linux. These steps work 
for popular Linux systems like Ubuntu, Debian, Linux Mint, and Pop!_OS.

--------------------------------------------------------------------------------
PART 1: FULL GNU GCC INSTALLATION STEPS
--------------------------------------------------------------------------------

STEP 1: Open the Terminal
Press "Ctrl + Alt + T" on your keyboard to instantly open a Terminal window.

STEP 2: Update the System Package Lists
Before installing new tools, ensure your computer knows about the absolute 
latest software versions available by running:

    sudo apt update

*Note: The terminal will prompt you for your Linux account password. Type 
it in (characters will not display as you type for security) and press Enter.*

STEP 3: Install the Build-Essential Suite
Linux bundles the GNU GCC compiler, G++ (C++ compiler), Make, and other core 
development headers into a single package called "build-essential". Install it 
by running:

    sudo apt install build-essential -y

STEP 4: Verify the Installation
Unlike macOS, Linux installs GNU GCC directly as your primary system compiler. 
Verify that it is installed and check its version by running:

    gcc --version


--------------------------------------------------------------------------------
PART 2: POPULAR SOFTWARE DEFINED RADIO (SDR) LIBRARIES
--------------------------------------------------------------------------------

With your GCC development tools ready, you can install the core frameworks and 
hardware drivers needed for Software Defined Radio directly from the standard 
Linux package manager.

1. GNU Radio Framework
The industry-standard development ecosystem for signal processing. It provides 
the runtime architecture and processing blocks to implement software radios using 
graphical flowcharts or C++/Python programming.

    Command: sudo apt install gnuradio -y

2. SoapySDR Library
A generalized C++ API and hardware abstraction layer. It acts as a universal 
plug-and-play middleware, allowing SDR application software to communicate seamlessly 
with varied physical radio hardware without custom codebases.

    Command: sudo apt install soapysdr-tools libsoapysdr-dev -y

3. Liquid DSP
A highly optimized digital signal processing library written entirely in C. It 
is designed specifically for software-defined radios on embedded systems, 
offering fast, lightweight filtering, modulation, and synchronization algorithms.

    Command: sudo apt install libliquid-dev -y

4. Librtlsdr Driver
The essential user-space driver library required to control cheap, ubiquitous 
Realtek RTL2832U-based USB dongles, turning budget TV tuners into wideband SDR 
receivers.

    Command: sudo apt install rtl-sdr librtlsdr-dev -y
